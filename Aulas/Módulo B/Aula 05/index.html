Variáveis e Tipos Primitivos

Em programação, uma variável é um espaço na memória do computador que armazena dados que podem ser alterados durante a execução de um programa. Cada variável possui um nome único e um tipo de dado associado, que define o tipo de valor que ela pode armazenar.

Na aula anterior não tinha onde eu guardar a opção que foi clicada pelo usuário, se ele tinha clicado em "Ok" ou "Cancelar", então eu não tinha como saber qual foi a opção escolhida. Para resolver isso, podemos usar variáveis.

Uma outra coisa, quando utilizamos o window.prompt() para receber dados do usuário, o valor digitado é sempre retornado como uma string, mesmo que seja um número. Por isso, precisamos converter esse valor para o tipo de dado correto antes de utilizá-lo em cálculos ou comparações.

Nós podemos definir uma variável em JavaScript utilizando as palavras-chave var, let ou const. A diferença entre elas está relacionada ao escopo e à mutabilidade da variável.

Além disso, o nome de cada variável, cada identificador, deve seguir algumas regras , como não começar com números, não conter espaços e não utilizar palavras reservadas da linguagem, ou seja, comandos que já possuem um significado especial na linguagem, como if, else, for, while, function, return, entre outros.

Existem 3 formas de delimitar uma string em JavaScript: usando aspas simples (' '), aspas duplas (" ") ou crases (` `). As crases permitem a interpolação de variáveis e expressões dentro da string, utilizando a sintaxe ${expressão}.

Data Types

No JS, não há diferencia entre números inteiros e números de ponto flutuante, todos são do tipo Number. Segue abaixo alguns exemplos:

  • Boolean - (true ou false);
  • String - (sequência de caracteres);
  • Null - (ausência intencional de valor);
  • Undefined - (variável declarada, mas não inicializada);
  • Infinity - Representar o infinito positivo.
  • NaN - (Not a Number)
  • Symbol - Representar identificadores únicos.
  • BigInt - Representar números inteiros grandes que excedem o limite do tipo Number.
  • Object - Representar entidades do mundo real, como pessoas, carros, produtos, entre outros;
  • Array - Representar listas, tabelas e outras estruturas de dados. Representar coleções de valores.
  • Function - Blocos de código reutilizáveis que podem ser chamados em diferentes partes do programa.
  • typeof - Operador que retorna o tipo de dado de uma variável. Escreva: 'typeof variavel' que ele retornará o tipo de dado da variável.
